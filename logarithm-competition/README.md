# مسابقة التابع اللوغاريتمي النيبري

لوحة معلم لإنشاء مسابقة من ٢٧ سؤالًا أو ١٨ سؤالًا، مع صفحة تقديم مستقلة لكل مجموعة.

## الاستخدام

1. افتح الصفحة وأنشئ كلمة مرور للمعلم.
2. أنشئ المسابقة وحدد اسمي المجموعتين والمدة.
3. نزّل صفحة كل مجموعة وأرسلها إليها؛ لا تعرض صفحات الطالبات درجات أو تصحيحًا.
4. تنزّل كل مجموعة ملف تسليم مشفّرًا بعد إكمال الاختبار وترسله إلى المعلم.
5. استورد ملفي التسليم في لوحة المعلم لعرض الدرجات والحلول والفائز.

الفائز هو صاحب الإجابات الصحيحة الأكثر، ثم الزمن الأقل عند التعادل.

## حفظ المسابقة

الدرجات والمفاتيح الخاصة محفوظة مشفّرة في متصفح المعلم؛ المستودع لا يتضمن نتائج أو كلمات مرور. لا تُرفع إجابات الطالبات إلى خادم تلقائيًا؛ يُجمع التسليم باستيراد الملفات. شفرة الصفحة المنشورة وبنك الأسئلة العام قابلان للاطلاع، وكلمة مرور المعلم تحمي بيانات مسابقاته المحفوظة محليًا.

احتفظ بكلمة المرور ونسخة احتياطية مشفّرة من اللوحة. عند الانتقال من الملف المحلي إلى رابط الموقع أو إلى جهاز آخر، استعد النسخة الاحتياطية داخل الرابط الجديد قبل استيراد التسليمات القديمة.
